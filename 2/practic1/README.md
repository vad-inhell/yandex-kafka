# 2 глава задание 1 - азработка функционала с применением библиотеки потоковой обработки данных.

Задача. Создайте систему обработки потоков сообщений с функциями блокировки пользователей и цензуры сообщений. Разверните систему с использованием Docker-сompose и настройте необходимые топики Kafka. 

Подзадача 1.  Блокировка нежелательных пользователей
Реализуйте поток обработки сообщений, в котором пользователи смогут блокировать других пользователей. Для этого: 
Создайте отдельный список заблокированных для каждого пользователя.
Этот список должен храниться в персистентном хранилище:
Python: table
Реализуйте автоматическую фильтрацию: сообщения от нежелательных пользователей не должны доходить до получателей. 

Подзадача 2. Цензура на слова
Создайте список запрещённых слов, который можно динамически обновлять.
Добавьте компонент, обрабатывающий поток сообщений и удаляющий или маскирующий запрещённые слова.
Все сообщения должны проходить через цензуру перед отправкой получателю.

## описание классов и логики работы

### 1 модели данных faust.Record
используются для автоматической сериализации/десериализации json из kafka в pythonобъекты:
- BlockEvent событие блокировки user, blocked, action
- BannedWordEvent событие управления словарем word, action
- MessageEvent сообщение from_user,to_user, text

### 2 персистентные хранилища app.Table
- blocked_table хранит пары user:blocked -> True/False позволяет мгновенно проверять, заблокировал ли получатель отправителя
- banned_words_table хранит список запрещенных слов word -> True/False. обновляется динамически без перезапуска приложения

### 3 агенты обработки @app.agent
- handle_blocks читает топик blocked_users и обновляет таблицу блокировок
- handle_banned_words читает топик banned_words и динамически обновляет словарь цензуры.
- handle_messages  основной конвейер.
  проверяет blocked_table ксли True — сообщение отбрасывается continue, не доходя до получателя
  если не заблокировано, применяет регулярное выражение re.sub для замены слов из banned_words_table на ***
  отправляет очищенный текст в топик filtered_messages
